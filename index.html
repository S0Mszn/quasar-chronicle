Technical Architecture
How Quasar Chronicle Works
1
Data Ingestion
SoSoValue Open API
All market intelligence originates from SoSoValue's API — the most comprehensive on-chain financial data platform available. Three endpoints power the entire product.
News & Research Feed
GET /api/v1/news/featured?pageNum=1&pageSize=20&categoryList=1,2
Powers hero lead story, three-column news grid, story list, and Research tab. Returns curated news categorised by type and asset.
ETF Flow Data
GET /api/v1/etf/summary
Powers ETF Watch dashboard and Markets sidebar. Returns BTC & ETH ETF AUM, daily flows, 7-day and 30-day flow data.
Authentication
Header: x-soso-api-key: [KEY]
All requests authenticated via SoSoValue Beta API key. Rate limit: 10 calls/min. Access via sosovalue.com/developer.
2
Execution Layer
SoDEX Testnet Integration
The SoDEX Terminal connects to SoDEX's testnet REST API for live orderbook data, real-time tickers, and trade execution routing.
Market Tickers
GET /api/v1/spot/markets/tickers
Live price, 24h change, volume for vBTC/vUSDC, vETH/vUSDC, SOSO/vUSDC pairs.
Order Book
GET /api/v1/spot/markets/{symbol}/orderbook
Real-time bid/ask depth for selected trading pair. 8 levels each side.
Trade Execution
POST /api/v1/spot/orders (EIP-712 signed)
Trade panel prepares and routes orders to SoDEX for wallet-signed execution. Connect MetaMask to complete trades on SoDEX testnet.
3
AI Editorial Engine
Groq AI — LLaMA 3.3 70B
SoSoValue data is synthesised into original financial journalism via a secure Vercel serverless proxy. The AI generates lead stories, daily briefings, ETF analysis, index commentary, and macro interpretation — autonomously on every request.
Autonomous Pipeline
SoSoValue APIs → AI Prompt → Groq LLaMA 3.3 70B → Published Article
Zero human editorial intervention. Every briefing is generated fresh from live SoSoValue data on every page load.
