Technical Architecture · Wave 2
How Quasar Chronicle Works
An autonomous financial publishing pipeline — SoSoValue's 9-module API + SoDEX trading infrastructure + Groq AI editorial engine — zero human intervention required.
SoSoValue API · 9 Modules Used
Module 1 · Feeds
GET /openapi/v1/news/featured · GET /openapi/v1/news/hot
Powers the Markets hero story, three-column news grid, story list, and Research page. Featured news returns editorially curated articles with feature images, author data, and matched currencies. Real-time update frequency.
Module 2 · ETF
GET /openapi/v1/etfs/summary-history · GET /openapi/v1/etfs · GET /openapi/v1/etfs/{ticker}/market-snapshot · GET /openapi/v1/etfs/{ticker}/history
Powers the entire ETF Watch page — aggregate summary stats, 30-day historical inflow chart, individual ETF product cards with AUM and flow metrics. BTC, ETH, SOL, XRP ETF data available.
Module 3 · SoSoValue Index
GET /openapi/v1/indices · GET /openapi/v1/indices/{ticker}/market-snapshot · GET /openapi/v1/indices/{ticker}/constituents
Powers the Index Desk page with live SSI index prices, returns (7d/1m/3m/1y/YTD), and constituent weights for MAG7.ssi, Layer1.ssi and other SoSoValue proprietary indices.
Module 4 · Currency & Market Data
GET /openapi/v1/currencies/{id}/market-snapshot · GET /openapi/v1/currencies/{id}/klines
Powers the market snapshot cells (price, 24h change, high/low, market cap, ATH) and the 7-day price chart for BTC, ETH, SOL, BNB. Watchlist filtering uses currency IDs to personalise the news feed.
Module 5 · Macro
GET /openapi/v1/macro/events
Powers the Macro page economic calendar — Fed meetings, CPI releases, NFP, and other macroeconomic events. AI generates contextual analysis for each upcoming event using this data as input.
SoDEX API · Execution Module
GET testnet-gw.sodex.dev/api/v1/spot/markets/tickers · GET /markets/{symbol}/orderbook · GET /markets/{symbol}/trades
Powers the SoDEX Terminal — live ticker prices, real-time orderbook depth (8 levels bid/ask), recent trade history. Trade execution routes to SoDEX via EIP-712 wallet signing. ValueChain Layer 1 testnet.
AI Editorial Engine
Groq API · LLaMA 3.3 70B · POST /api/brief (Vercel proxy)
All SoSoValue data feeds are synthesised by the AI editorial engine to produce lead stories, daily briefings, ETF analysis, index commentary, and macro event interpretation. The proxy keeps API keys secure server-side.
